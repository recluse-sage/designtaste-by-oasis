# Changelog

## v0.1.0-beta - 2026-10-21

- First beta of `designtaste-by-oasis`: thin orchestrator skill with
  mandatory brainstorming gate, layout / taste / buttons / copy-slim
  phases, questionnaire + collector, 3 wireframes, `:8000` red/green
  review with `design-feedback.md` persistence, and a token-based
  `design-system.md` writer with the check-ask-update rule.
- Plugin bundle layout (`.claude-plugin/plugin.json`), skills.sh
  targeting, and deterministic `tests/test_*.sh` graders.
- Known limits: local files only, no hosted backend; V1 keeps icons
  and full animation choreography deferred.
