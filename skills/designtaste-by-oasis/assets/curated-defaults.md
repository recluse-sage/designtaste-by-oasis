# Curated defaults

Fallback examples used when systemdesignhunt picks or user links are
unreachable. scripts/collect.py uses these and notes the fallback
explicitly instead of failing.

## 1. Linear-style product page

- URL: https://linear.app
- Notes: stacked single-focus sections; pill primary CTAs; dark surfaces with one accent; minimal entrance motion.

## 2. Stripe-style marketing plus docs

- URL: https://stripe.com
- Notes: airy sections with strong hierarchy; quiet secondary buttons beside one primary; flat light backgrounds; restrained color.

## 3. Vercel-style minimal developer page

- URL: https://vercel.com
- Notes: monochrome palette, type-led hero; single dark CTA; generous whitespace; grid arrangement stacking to one column.

## 4. Apple-style product storytelling

- URL: https://www.apple.com
- Notes: full-bleed media sections; scroll-driven reveals; big type, few buttons; dark/light alternating bands.

## 5. Notion-style calm productivity page

- URL: https://www.notion.so
- Notes: flat light backgrounds; short inline forms; friendly illustration over 3D; low-motion, scannable copy blocks.

## 6. Raycast-style sharp utility page

- URL: https://www.raycast.com
- Notes: compact sections with command-bar motif; crisp modals with explicit close; subtle glow backgrounds; fast hover feedback.

## 7. Arc-style expressive browser page

- URL: https://arc.net
- Notes: playful aesthetic, bold color moments; rounded forms and modals; characterful arrangement without clutter.
