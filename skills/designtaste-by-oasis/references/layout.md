# Layout

Capture IA, section hierarchy, and wireframe skeleton before any
visual styling. Output a section-by-section skeleton, not finished
design.

## Steps

1. List information architecture: pages (or single-page anchors)
   in order, one line each with purpose.
2. Define hierarchy per page: exactly one primary focus, then
   secondary and tertiary blocks in reading order.
3. Sketch the wireframe skeleton: section order, approximate weight
   (hero / narrow / full-bleed), and placement of CTAs.
4. Validate against the fixed part checklist below: every part gets
   a verdict (in scope / deferred) so nothing is silently dropped.

## Fixed part checklist

Cover each part for every direction. Mark verdict per part.

- [ ] sections - page/anchor order and purpose.
- [ ] buttons - placement in layout (which sections carry CTAs).
- [ ] modals - which flows need overlays, what triggers them.
- [ ] backgrounds - section background rhythm (flat / split / media).
- [ ] color - placement roles (primary surface, accent slots), not values.
- [ ] 3D - candidate slots for depth elements, or explicit none.
- [ ] animation - motion slots (entrance, scroll, hover), V1 scan only.
- [ ] forms - fields per form, order, submit placement.
- [ ] aesthetic - one-line feel per section (dense / airy / bold).
- [ ] arrangement - grid behavior: stacking, columns, breakpoints intent.

## Output

A short skeleton: IA list + hierarchy notes + checklist with
verdicts. Keep it scannable; details belong to later phases.
