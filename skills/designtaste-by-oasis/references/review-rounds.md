# Review rounds (multi-round gate)

One pick needs more than one look. Do not finalize after one round.

## Gate

- [ ] After Save, ask: "another round or pick?" and record the answer in `design-feedback.md`.
- [ ] Never finalize after a single round without an explicit user pick.
- [ ] If the user picks, write the picked direction id explicitly.
- [ ] If another round, apply feedback and re-review before asking again.
